# Анализ рейтингов шоколадных плиток

## Описание
Анализ данных о шоколадных плитках для разработки системы предсказания рейтинга.

## Задача
- **Тип**: Регрессия
- **Целевая переменная**: Рейтинг (1-5)
- **Признаки**: процент какао, страна происхождения, производитель
- **Метрика**: RMSE

## Данные
- **Источник**: Kaggle (TidyTuesday)
- **Размер**: 2530 записей
- **Период**: 2006-2021
